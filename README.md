## Local Development

To run the website locally, you can use the provided npm scripts. The server will run on port 3000 using the [\`serve\`](https://www.npmjs.com/package/serve) package.

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local server:
   ```bash
   npm start
   ```

The site will be served at `http://localhost:3000`.
